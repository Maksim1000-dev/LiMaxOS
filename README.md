# LiMaxOS

Мини-ОС для x86 в реальном режиме: двухступенчатый загрузчик на NASM и
графический рабочий стол 320x180x256 (16:9) с окнами, мышью, панелью задач и
терминалом. Загрузчик показывает минимальный чёрный экран: большую неоновую
букву `L` и полосу загрузки с реальным прогрессом чтения дискеты, после чего
открывается рабочий стол LiMaxOS.

## Запуск

Дважды кликни `START.BAT`.

Скрипт сам:

1. собирает `boot/boot.asm`, `boot/loader.asm` и `kernel/kernel.asm` через NASM;
2. компилирует `tools/mkimg.c` через GCC;
3. собирает флоппи-образ `build/LiMaxOS.img` (1.44 МБ);
4. запускает QEMU с этим образом.

Собрать без запуска:

```bat
START.BAT build
```

Если QEMU закрылся, окно консоли останется с сообщением. Для запуска без паузы:

```bat
START.BAT nopause
```

## Рабочий стол

- Иконка **TERMINAL** в левом верхнем углу.
- Двойной клик по иконке открывает терминал. Можно также выделить иконку одним
  кликом и нажать `Enter`.
- Окно терминала перетаскивается за заголовок.
- Кнопки окна: жёлтая — свернуть, зелёная — развернуть/восстановить,
  красная — закрыть. После сворачивания кнопка **TERMINAL** появляется на
  панели задач справа от `L`.
- Кнопка **L** в левом нижнем углу открывает меню: слева программа TERMINAL,
  справа Restart и Shutdown. `Esc` или повторный клик по `L` закрывают меню.

## Что происходит при загрузке

1. **Boot-сектор (512 байт)** читает первый сектор `LMAXLDR.SYS`, проверяет
   заголовок `LiMaxLdr`, узнаёт количество секторов и догружает остальные.
2. **LMAXLDR.SYS** рисует чёрный неоновый экран, определяет RAM через BIOS,
   читает `CORE.SYS` по одному сектору с LBA 64 и обновляет полосу **только
   после успешного чтения**. Если диск не отвечает, прогресс стоит на месте,
   а на экране появляется сообщение о повторной попытке.
3. После чтения проверяется контрольная сумма ядра, выполняется реальный тест
   320 КБ памяти (запись/проверка `AA55` и `5555`) и происходит переход в ядро.
4. **CORE.SYS** переключает VGA в режим 13h и запускает графический рабочий
   стол.

Задержка 25 мс между секторами добавлена только чтобы прогресс был виден
глазами. Она не двигает полосу сама по себе — полоса меняется после реального
чтения. Уменьшить/убрать задержку можно в `boot/loader.asm` по меткам
`mov ax, 25` / `call delay_ms`.

## Терминал

Команды вводятся в окне TERMINAL. `Enter` выполняет команду,
`Backspace` удаляет символ.

| Команда | Что делает |
| --- | --- |
| `HELP` | список команд |
| `VER` | версия LiMaxOS |
| `DIR` | фиктивный список файлов |
| `CLS` | очистить экран |
| `ECHO текст` | напечатать текст |
| `MEM` | обычная/расширенная память |
| `TIME` | время из RTC |
| `DATE` | дата из RTC |
| `ABOUT` | информация о системе |
| `REBOOT` | перезагрузка |
| `POWEROFF` | выключение QEMU через ACPI |
| `HALT` | остановка процессора |

## Структура проекта

```text
START.BAT              сборка и запуск
boot/boot.asm          boot-сектор, LBA 0
boot/loader.asm        LMAXLDR.SYS, LBA 1
kernel/kernel.asm      CORE.SYS: точка входа и главный цикл
kernel/gfx.inc         палитра, шрифт, примитивы, back buffer
kernel/mouse.inc       PS/2-мышь, IRQ12
kernel/term.inc        буфер терминала и команды
kernel/ui.inc          рабочий стол, окно, панель задач, меню L
tools/mkimg.c          сборщик образа и патчер заголовков
tools/maximize.ps1     разворачивает окно QEMU при старте
tools/ppm2png.py       необязательный конвертер скриншотов QEMU (только stdlib)
build/                 результаты сборки
```

## Формат образа

- 1.44 МБ, геометрия 80 цилиндров / 2 головки / 18 секторов.
- LBA 0: boot-сектор с сигнатурой `55 AA`.
- LBA 1: `LMAXLDR.SYS`, заголовок 32 байта:
  `LiMaxLdr`, число секторов, сегмент загрузки, точка входа, размер, контрольная
  сумма.
- LBA 64: `CORE.SYS`, такой же заголовок с магией `LiMaxOSK`.

`mkimg.exe` сам считает количество секторов и контрольные суммы, поэтому
исходники можно менять без ручной правки размеров.

## QEMU

Запускается так:

```bat
qemu\qemu-system-i386.exe -name "LiMaxOS" -machine pc -m 16M ^
  -drive "file=build\LiMaxOS.img,format=raw,if=floppy" ^
  -boot a -rtc base=localtime -vga std ^
  -display gtk,zoom-to-fit=on,show-menubar=on,keep-aspect-ratio=off,gl=off
```

QEMU стартует в обычном окне, развёрнутом на весь экран. Сверху остаются
заголовок и меню QEMU: окно можно таскать, сворачивать, разворачивать и
растягивать за края, а картинка LiMaxOS подстраивается под новый размер
(`zoom-to-fit`). QEMU по умолчанию масштабирует без сглаживания, поэтому
пиксели остаются чёткими.

Настоящий полноэкранный режим без меню — `Ctrl+Alt+F`; повторное нажатие
возвращает окно. `Ctrl+Alt+0` сбрасывает масштаб, `Ctrl+Alt++` и `Ctrl+Alt+-`
меняют его вручную.

`-m 16M` даёт около 639 КБ обычной памяти и ~15 МБ расширенной.

Ядро переключает mode 13h в 320x180 (16:9), QEMU отдаёт кадр 640x360. В
настоящем полноэкранном режиме на 2560x1440 это ровно 8x относительно
пикселей ОС, на 1920x1080 — 6x, на 1280x720 — 4x. В оконном режиме картинка
заполняет доступную область окна без чёрных полей
(`keep-aspect-ratio=off`), поэтому при нестандартной пропорции окна она
слегка растягивается.

В простое главный цикл уходит в `HLT` и просыпается по прерываниям таймера,
клавиатуры или мыши, поэтому QEMU не нагружает процессор на 100%.

Для тестов без окна удобно использовать монитор и обязательно закрывать QEMU
командой `quit`:

```bat
qemu\qemu-system-i386.exe -display none ^
  -drive "file=build\LiMaxOS.img,format=raw,if=floppy" -boot a ^
  -monitor tcp:127.0.0.1:5555,server,nowait
```
